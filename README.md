# 🧮 BMI Calculator – Web Application

A simple, responsive, and user-friendly BMI (Body Mass Index) Calculator web application that calculates BMI based on a user's height and weight. It displays the BMI result along with the corresponding health category.

## 🚀 Features

- Calculate BMI using height and weight.
- Display accurate BMI results.
- Show BMI health categories.
- Simple and attractive user interface.
- Responsive design for different screen sizes.
- Easy-to-use input fields.
- Instant calculation using JavaScript.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – BMI calculation and functionality

## 📊 BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal Weight |
| 25 – 29.9 | Overweight |
| 30 or above | Obese |

## 🧮 BMI Formula

BMI = Weight (kg) / Height (m)²

## 💻 How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter your height and weight.
5. Click the Calculate button to see your BMI result.
