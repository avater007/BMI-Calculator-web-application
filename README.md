# BMI Calculator Web Application

## 📌 Project Description
The BMI Calculator is a simple and responsive web application that calculates Body Mass Index (BMI) based on the user's height and weight. It displays the BMI result along with the corresponding health category.

## 🚀 Features
- Calculate BMI instantly.
- Enter height and weight.
- Display BMI results.
- Identify health categories:
  - Underweight
  - Normal Weight
  - Overweight
  - Obesity
- Simple and user-friendly interface.
- Responsive design for different devices.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enter your height and weight.
5. Click the Calculate BMI button to view your result.

## 🧮 BMI Formula

BMI = Weight (kg) / Height (m)²

## 🎯 Project Objective
The main objective of this project is to develop a simple web application that helps users calculate their BMI and understand their weight category.
